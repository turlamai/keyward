保密即界面，状态即安全。

四个界面钉死日常体验：概览、轮换、快照、散钥扫描——值不上屏，暴露必披露，破坏必确认。

状态点概览

每个产品、每把钥匙独立判定：配对、注意、中性、空节四态贯穿侧栏圆点与徽标——一个坏 key 不会被同节的好 key 掩盖，多 key 节按名字逐个标注指纹。

两阶段轮换，Promote 防错

Stage 把新钥写进 NEXT 条目，旧钥继续发布不受影响；Promote 由配对结果把关，配对不绿按钮不亮。丢弃也要过确认对话框，Return 永远落在取消。

快照先行，一键恢复

生成、导入、修改、删除，每次写入先落整库快照，快照跟库一起进同步盘；出事时 Restore 就是一次点击，每台设备上都有底。

散钥扫描，只报指纹

扫工作树找未收编的私钥材料，路径 / 行号 / 类型 / 指纹逐行列出——PEM 头、base64-DER、Sparkle 种子都能认，值永不显示。

设计原则

保密即界面

界面上不存在「值」：列表与体检结果只载名字、计数与指纹——SHA-256 指纹取前 16 位 hex，是唯一允许的派生标识。值唯一的出口是显式复制。

暴露必披露

每次复制当场宣告「剪贴板任何应用可读」，30 秒后自动清除，后台清除同样播报，永不静默。Copy as… 导出 Sparkle / minisign / Tauri 格式走同一套披露。

防错一致

生成、暂存、晋升、丢弃、删除一律过确认对话框：安全动作拿视觉主位，Return 永远落在取消，破坏性动作必须显式点击；删除文案先讲条目用途，再讲快照可恢复。

明文可逃生

库是同步盘里的明文 INI——格式稳定、随时离开，Keyward 是纪律层不是锁。引擎零网络代码，密钥不出本机；防失窃交给 FileVault / BitLocker。

三步开始

指向你的库

首次启动选择你的钥匙库（任何同格式的 INI 都行），选择会被记住——不新建格式、不强迫迁移，你的同步盘继续是唯一事实源。

Deep Check 一键体检

解析每把私钥、派生公钥、算指纹、和库内公钥配对——过去一下午的手工 openssl，现在一屏读完。

改即有底

生成、导入、修改、删除，每一步都先落快照；应用内生成直接写进库，连瞬时散件都不存在。要回滚，恢复就是一次点击；值想用时复制进剪贴板，永不回显。
